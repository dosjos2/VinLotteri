# VinLotteri

Et C#-program for trekning av vin og andre premier, laget for Nytt Krutt 2012. Dette er en Windows Forms-applikasjon for .NET Framework 4.0.

## Innhold

- `VinLotteri.sln`: Visual Studio-løsning.
- `VinLotteri/`: applikasjon med hovedvindu, vinnervindu og grafvindu.
- `VinlotteriTest/`: eksisterende tester.
- Rotmappen inneholder også historiske publiserings- og Visual Studio-filer.

Den opprinnelige README-en med kjøreinstruksjon og merknad om installasjonsfilen er bevart nedenfor.
